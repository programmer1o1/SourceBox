# SourceBox v3.7.0

This release focuses on making the Voidside scene feel closer to the original ARG footage while making SourceBox easier to maintain and usable with CrossOver on macOS.

## Voidside scene accuracy

- The camera now drifts left while keeping the interloper.dme dot and cone centered.
- Vertical tracking drift was removed so the target no longer jumps above or below screen center after teleporting.
- Random camera roll remains part of each teleport.
- Teleport pacing now varies naturally, with uncommon rapid cuts and occasional multi-second holds.
- The centered dot and cone retain their short stutter movement and snap back to center.
- Floating XYZ pointers move independently. Half rotate slowly while the rest keep a fixed orientation.

## macOS and CrossOver

- Added native detection of CrossOver bottles, Steam installations, and Steam libraries.
- Source games launched through Wine and CrossOver command wrappers can now be recognized.
- File-based VScript and Garry's Mod Lua bridges work from the native macOS build.
- Added a packaged macOS app and automated macOS release builds.
- Added persistent diagnostics at `~/Library/Logs/SourceBox/sourcebox.log`.

Picker and cube summoning were verified in a CrossOver Source game.

## Project structure and reliability

- Split the large application files into focused `sourcebox/` modules.
- Extracted Lua and VScript payloads into versioned `bridge_scripts/` resources.
- Added tests for camera behavior, teleport timing, pointer rotation, bridge coordination, script integrity, Steam discovery, and CrossOver paths.
- Added `ARCHITECTURE.md` to document module ownership and behavior-sensitive areas.
- Added the SourceBox logo and expanded macOS installation guidance in the README.
