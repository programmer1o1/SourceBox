# SourceBox v3.9.0

This release rebuilds the main menu to match the original reference, adds VScript support for Left 4 Dead 2, Portal 2, CS:GO, Alien Swarm and Strata Source games, and makes SourceBox remove everything it installs into games when it closes.

## Main menu

- The camera, lighting, checkerboard and the cube, sphere and cone now match the original reference image, including the sphere's shadow on the cube.
- Clicking the cube moves it to the reference pose and spins it in a lighter blue. The sphere now always draws in front of it.
- The checkerboard edges are softened to match the reference.
- Clicking and hovering now follow each shape's real outline. The sphere can be clicked anywhere it shows, even while the cube is spinning.
- 4x anti-aliasing in every scene. On drivers that ignore the request, as some virtual machines do, frames go through an offscreen anti-aliased buffer instead.
- New README screenshot.

## New VScript games (experimental)

- Left 4 Dead 2, Portal 2, Counter-Strike: Global Offensive (legacy `csgo.exe`, not CS2), Alien Swarm, Portal 2: Community Edition and Portal: Revolution.
- Spawn the cube from SourceBox where you are looking, and one cube auto-spawns near you on each map load. Cubes keep the model's own colours.
- Strata Source games (P2CE, Portal: Revolution) are found by their engine files, so no folder names are needed.
- Portal 2's own `mapspawn.nut` is kept and still runs before SourceBox's.
- These games run while they are open, and the bridge starts on the next map load. Spawn results appear in the game console.
- Verified in Portal 2: Community Edition. The other games are tested only against a stand-in engine built from their documentation, so please report what you find.
- No Picker in these games yet: Portal 2, CS:GO and Alien Swarm scripts cannot read or set the view angles.

## Automatic cleanup

- Everything SourceBox installs into a game (scripts, the Garry's Mod addon, command files) is removed when SourceBox closes, and any game file it replaced is restored.
- If SourceBox is killed or crashes, a small background copy of it cleans up instead. Anything still left is cleaned at the next start.
- Files you edit after SourceBox writes them are left alone.
- On the new VScript games, closing SourceBox mid-map stops the in-game bridge. If the game was paused at the time, you may see one "Script not found" line in its console first.
- A record of installed files lives in `installed.json` in SourceBox's log folder.

## Garry's Mod

- Supports the 64-bit launcher, `gmod_win64.exe`, including when it starts without a `-game` argument.

## Internals

- New tests for rendering helpers, picking, the new VScript bridge, cleanup and GMod detection. The newer-branch bridge script can also run in a real Squirrel interpreter when `SOURCEBOX_SQUIRREL` points to one.
