# SourceBox v3.8.1

This release fixes a severe lag in v3.8.0, especially on Windows, caused by automatic demo detection.

## Fixes

- Fixed heavy lag and mouse stutter introduced in v3.8.0. Demo detection listed open files for every process inside the app, and `psutil` holds Python's global lock while doing so, which froze rendering.
- Demo detection now runs in a separate hidden worker process that exits when SourceBox does, so it can never stall the app.
- Only likely Source game processes are checked, and that list refreshes every few seconds instead of scanning everything every second.

## Notes

- PULL mode and automatic demo detection work as in v3.8.0. Verified in CrossOver on macOS, including the Windows build.
- Known limitation: recording a demo also triggers PULL mode.
- The README now documents PULL mode, the **P** key, and how demo detection works.
