# SourceBox v3.8.0

This release adds PULL mode to the Voidside scene, including automatic detection of Source demo playback, and makes the floating XYZ pointers tumble.

## PULL mode

- Press **P** in the Voidside scene to show an italic, red-orange "P U L L" on screen.
- Toggling it on plays the click sound, stops the music, and holds the current dot and red triangle instead of teleporting to the next target. The rest of the scene keeps animating.
- Toggling it off restarts the music and resumes teleporting.

## Automatic demo detection

- SourceBox now detects when a demo is playing in a Source game and enters PULL mode on its own, then leaves it when the demo stops.
- Detection watches for an open `.dem` file using `psutil` in a background thread, so it needs no launch options or game-side script and does not affect frame rate.
- Entering the Voidside scene while a demo is already playing starts in PULL mode.
- Verified on macOS with Counter-Strike: Source and Half-Life 2: Deathmatch through CrossOver. Linux and Windows are expected to work but are untested.
- Known limitation: recording a demo also triggers PULL mode.

## Floating XYZ pointers

- Every pointer now rotates on all three axes at 15 to 30 degrees per second, so they all look like they are floating and tumbling. Previously only half rotated, slowly.

## Internals

- The pygame text path now supports letter spacing and italic.
- Added tests for PULL mode and the demo watcher.
