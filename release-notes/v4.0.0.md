# SourceBox v4.0.0

SourceBox 4.0 improves custom cube physics across the newer Source branches and adds Picker controls to three more games. The main menu keeps the ARG presentation.

## Custom cube and game support

- **Portal 2 and Alien Swarm** load the custom SRCBOX cube during map startup so it can spawn as a physics prop.
- **Left 4 Dead 2** spawns the custom cube with server-side physics.
- **Portal: Revolution** is detected on older builds and under CrossOver. Its map-start script can precache the cube when the map's entity override is unavailable.
- **Legacy CS:GO** uses Metamod:Source and Stripper:Source for cube physics on stock maps. SourceBox can install the add-ons for 32-bit Windows builds, including CrossOver. Start the game with `-insecure`. If SourceBox installs the add-ons, restart CS:GO once with SourceBox still open, then load the map.
- **Portal 2: Community Edition** still supports custom cube spawning through the Strata bridge.

Install the custom model as described in the README, start SourceBox while the game is running, then load a local map. Maps that require a precached cube can skip spawning if the model has not loaded. SourceBox removes its temporary game files when it closes and restores any configuration it replaced.

## Picker

- **Left 4 Dead 2** uses `!picker` and `!pickernext` in chat for the local survivor host. Chat confirms when Picker is enabled or disabled.
- **Stock Portal 2** supports Picker in local single-player maps. Its bridge starts after save restoration, and the **PICKER ON** indicator stays steady while enabled.
- **Legacy CS:GO** supports Picker in a local practice match with one human player. It can target enemy bots, teammates, and physics props.

For stock Portal 2 and legacy CS:GO, enable `sv_cheats 1`, then use `script PickerToggle()` to toggle Picker and `script PickerNext()` to cycle targets.
